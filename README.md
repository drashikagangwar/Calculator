# 🧮 Python Calculator

A simple **Calculator project built using Python**. This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* User-friendly input
* Handles basic arithmetic calculations

## 🛠️ Technologies Used

* **Python 3**

## 📂 Project Structure

```text
Calculator/
│
├── calculator.py
└── README.md
```

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this project.
3. Open the project folder in VS Code or Terminal.
4. Run the following command:

```bash
python calculator.py
```

Enter first number: 10
Enter second number: 5
